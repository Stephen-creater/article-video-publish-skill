# 02 发布版（发平台用的小文件）

- 从母版 `05_视频工程/<slug>/renders/final.mp4` 压，先输出到临时目录：
  `ffmpeg -i <母版> -c:v libx264 -preset slow -tune animation -crf 25 -maxrate 6M -bufsize 12M -pix_fmt yuv420p -profile:v high -c:a copy -movflags +faststart <临时>/<slug>_发布版.mp4`
- 核对：时长和母版一致、有音轨、VMAF ≥ 92（`ffmpeg -i 发布版 -i 母版 -lavfi libvmaf -f null -`）。
- 通过后移到 `06_成片/<类别>/<slug>/<slug>_发布版.mp4`。原成片不覆盖，母版一直保留。
- 实测：3 分半的片子 417MB → 124MB（横屏）/ 47MB（竖屏），VMAF 95 左右，肉眼看不出差别。
