# 05 话题 tag

每条都给四套，写进 `10_封面/<slug>/发布文案.md`，并在对话里各放一个代码块：

| 平台 | 格式 | 数量 |
|---|---|---|
| 小红书 | `#话题` 空格分隔 | 10–12 个 |
| 视频号 | `#话题` 空格分隔 | 8 个左右 |
| 抖音 | `#话题` 空格分隔 | 5–6 个 |
| B 站 | 标签栏逐个添加，不带 #，逗号分隔 | 最多 10 个 |

选词：本片核心概念（2–3 个）+ 大类（AI、人工智能、个人成长、认知）+ 内容形式（深度思考、知识分享）。不放和内容无关的热门词。

## 发布文案.md 模板
```
# 发布文案
标题：<定下的标题>

小红书：#… #…

抖音：#… #…
B站标签：…,…
```
