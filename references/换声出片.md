# 换声出片

**以下命令都在 `根目录/05_视频工程/<slug>/` 里执行。** 各片装配脚本不同，先读本片 `QA.md`，按它记录的脚本和参数走。开工先执行：
```
P=../../03_工具; S=/Users/a1-6/Downloads/文章转视频/.claude/skills/article-video-publish/scripts
```

## 音色和费用
- 只用 `StephenMic01`（MiniMax，speech-2.8-hd，已激活）。其他 Stephen* 是试听音色，正式合成一次扣 9.9 元，不要用。
- 每条合成约 1–2 元（含试速和机械句重配），多条同时做时余额要留足。开工前 `python3 $P/tts_minimax.py check` 确认 Key 有效；余额不确定就先问 Stephen。

## 换声必守（2026-10-12 RAG 返工后定下，Stephen 确认「连贯多了」）
- **读法**：narration.json 的 `say` 多是当年给机器音「云希」写的（`R A G`、`M C P`、`SKILL 点 M D`、英文音译成中文）。原样送 MiniMax 会一个字母一个字母地念，又慢又机械。合成前逐条审：英文术语、产品名、人名按原文写法送；只有确实念不对的才写 say（先单句试合成，whisper 识别时句首补 0.6 秒静音再判断）。say 不能比字幕多出内容。
- **机械感检测**：全片合成后逐句测「扣掉停顿的语速偏离」和「基频起伏（半音标准差）」，以 Ontology 那条（`05_视频工程/2026-09-16_一文讲透AI热词_本体_Ontology/audio/vo_stephen`）为有人味的参照，按参照分布定阈值。被判机械的单句重配 2–4 版，挑读对、语速和语调正常的；新版不比旧版好就留旧版。现成脚本：RAG 那条工程里的 `measure_vo.py`、`mech_score.py`。
- **字幕偏早**：MiniMax 逐字时间把逗号停顿算进下一个字，停顿后的字幕会早出、句尾字幕会提前消失。按配音音量校正（参考 KV Cache 那条 `align_words.py`、智能涌现那条 `fix_cap_sync.py`）。
- **限流和余额**：多条同时合成会撞 1002 限流，在外面套循环续跑（已合成的自动跳过）；报 1008 余额不足立刻停，请 Stephen 充值。续跑前核对 `vo_stephen/` 的 wav 和 `tts_result.json` 是否一致，防止重复扣钱。

## 步骤
1. **备份**（只备份存在的文件；2026-10-11 清理后很多工程已没有 `mix.wav`、`video_silent.mp4`，缺了就跳过）到 `audio/机器配音版备份_云希/`：`audio/` 下的 `vo/ tts_result.json tts_input.json timeline.json subtitles.srt bgm.wav bgm.json sfx.json mix.wav mix.report.json vo_full.wav asr_check.json`（有 `bgm_edit.wav` 也带上），加 `index.html` 和装配脚本会重写的文件（QA 里写明的 `compositions/`、`assets/hosts.js`、`build/starts.json` 等）。`renders/final.mp4` → `final_机器配音版.mp4`。
2. **合成**：
   ```
   $P/.venv/bin/python $P/make_timeline.py tts-input
   rm -f audio/tts_result.json
   python3 $P/tts_minimax.py synth audio/tts_input.json -o audio/vo_stephen \
     --manifest audio/tts_result.json --voice-id StephenMic01 --speed 1.25 --model speech-2.8-hd
   ```
3. **定语速**：`$P/.venv/bin/python $P/make_timeline.py build --outro <按QA>`，看打印的「含停顿整体 x 字/分钟」，要 330–355。超了降速（如 1.22），不够升速；重配前把旧版留着：`audio/vo_stephen` → `audio/vo_stephen_语速1.25`，`audio/tts_result.json` → `audio/tts_result_stephen_语速1.25.json`。经验：演化 1.25、天赋 1.22、生产者 1.25、OpenAI 2028 1.18（英文和数字多的稿子要更慢）。
4. **字幕**：本片断词脚本（`recaption.py` 或 `fix_caps.py`）→ 有不足 0.45 秒的短块就 `$P/.venv/bin/python $S/merge_short_caps.py` → `$P/.venv/bin/python $P/build_captions.py`（`--width/--height/--css/--anim` 与原 `compositions/captions.html` 一致）。
5. **核对**：`$P/.venv/bin/python $P/asr_check.py`。say 读法、重复词被识别合并（如「过多的…过多的…」）不算错；拿不准就逐 0.1 秒看音量确认没有缺段。
6. **装配**：本片的 `assemble.py` 或 `build.py`。
7. **配乐音效**：
   ```
   $P/slot.sh bgm 2 $P/.venv-audio/bin/python $P/bgm.py --style <同原片> --seed <同原片> \
     --duration <timeline.json 的 total> --markers <场景起点,逗号分隔> -o audio/bgm.wav
   ```
   **必须给 `--duration`**，否则只生成 60 秒。原风格和种子看 `audio/bgm.json`。之后跑本片的 `make_sfx.py`（用 `.venv-audio`）。
8. **自检**：`npx hyperframes lint`、`npx hyperframes check`、`npx hyperframes snapshot --at <若干秒>`，看联系表。check 报 failed 时对照 QA 里记录的已知项（如报纸层叠的 content_overlap），数量和类型一致就不算新问题。
9. **渲染与质检**：`$P/render_queue.sh`（约 10 分钟，放后台）→ `$P/.venv-audio/bin/python $P/mix.py …`（参数按 QA）→ `$P/.venv/bin/python $P/qa.py` 必须 pass → `$P/.venv/bin/python $P/deliver.py`（06 里只留 `<slug>_发布版.mp4` 和字幕，旧版自动挪回 `05_视频工程/<slug>/旧版成片/`，并更新 `08_日志/进度.json`）。
   交付后把 `renders/video_silent.mp4` 移到废纸篓（`mv renders/video_silent.mp4 ~/.Trash/`，画面和 final.mp4 一样，需要时 `ffmpeg -i renders/final.mp4 -an -c:v copy` 取回）；换声前的机器配音母版 `final_机器配音版.mp4` 也移到废纸篓（`旧版成片/` 里有压缩版）。不要永久删除，清空废纸篓由 Stephen 自己做。
10. **发布版**：
    ```
    ffmpeg -i renders/final.mp4 -c:v libx264 -preset slow -tune animation -crf 25 -maxrate 6M -bufsize 12M \
      -pix_fmt yuv420p -profile:v high -c:a copy -movflags +faststart <临时目录>/<slug>_发布版.mp4
    ffmpeg -i <临时目录>/<slug>_发布版.mp4 -i renders/final.mp4 -lavfi libvmaf -f null - 2>&1 | grep "VMAF score"
    $S/loudnorm14.sh <临时目录>/<slug>_发布版.mp4 <临时目录>/<slug>_发布版_-14.mp4
    ```
    **音量必须提到 -14 LUFS**（2026-10-22 起）：母版混音是 -16，原样上传平台会提示「音量偏低」。loudnorm14.sh 两遍标准化，只重编码声音、画面直接复制；打印的 I 要是 -14.0 左右、Peak 不高于 -1 dBFS。
    VMAF ≥ 92、-14 版时长和母版一致（差 0.1 秒内）、有音轨后，把 `_发布版_-14.mp4` 改名为 `<slug>_发布版.mp4`，覆盖 `根目录/06_成片/<类别>/<slug>/` 里同名文件（deliver 放的是母版副本）。
11. `QA.md` 追加「换成 Stephen 本人声音」一节（语速、费用、字幕处理、质检结果）。
